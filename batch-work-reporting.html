项目占比设置

随机生成占比规则说明

核心规则：

  • 每个人单独随机生成，互不影响
  • 只给该人员参与且当月有效的项目生成占比
  • 每个人的项目占比总和固定为 100%
  • 已勾选人员时只处理所选人员；未勾选时处理全部人员
  • 每个项目至少分配 5%，避免极端小值
  • 每次点击都会产生不同结果

算法步骤（开发实现参考）：

  1. 给每个项目分配 5% 的基础值
  2. 计算剩余百分比：剩余 = 100 - (5 × 项目数量)
  3. 随机分配剩余部分：循环添加 5-15% 直到用完
  4. 打乱顺序，让分布更自然

提示：生成后您仍可以手动调整个别项目的占比！

随机分配规则说明

核心思路：每天按当日有效项目分配并带随机波动，避免有效项目出现大面积0值

计算步骤：

  • 1. 每天先筛选当日有效项目
  • 2. 当日基准值 = 考勤工时 × 项目占比 ÷ 当日有效项目总占比
  • 3. 每个项目在基准值基础上做 ±30% 随机波动，再统一调整到当天考勤工时

波动规则详解：

• 波动方式：所有项目自由波动，最后统一调整

• 简化公式：临时分配 = 基准值 × (1 + 随机波动[-0.3, +0.3])

• 最终调整：实际分配 = 临时分配 × (考勤工时 ÷ 总和)

• 优点：

① 所有项目都能波动，看起来自然

② 代码简单，不需要复杂的剩余空间检查

③ 永远不会超过考勤工时（统一调整保证）

• 例子：

考勤8h，三个项目临时分配总和8.5h（超标0.5h）

调整比例 = 8h ÷ 8.5h = 0.941

每个项目 × 0.941 → 总和变为8h ✓

示例（四个项目）：

基础数据：

- 张三6月总工时：176h（22个工作日）

- 设置占比：智能传感器研发 30%，工业机器人 25%，新能源材料 25%，物联网平台 20%

- 月目标：智能传感器研发 52.8h，工业机器人 44h，新能源材料 44h，物联网平台 35.2h

 

每日分配过程（方案A：所有项目波动，统一调整）：

6月1日（考勤8h）：

第一步：所有项目自由波动

- 智能传感器研发：基准 2.4h → +15%波动 → 临时 2.76h

- 工业机器人：基准 2.0h → -10%波动 → 临时 1.8h

- 新能源材料：基准 2.0h → +5%波动 → 临时 2.1h

- 物联网平台：基准 1.6h → +10%波动 → 临时 1.76h

- 临时总和：2.76+1.8+2.1+1.76=8.42h（超过考勤）

第二步：统一调整

- 调整比例 = 8h ÷ 8.42h = 0.95

- 智能传感器研发：2.76 × 0.95 = 2.62h

- 工业机器人：1.8 × 0.95 = 1.71h

- 新能源材料：2.1 × 0.95 = 2.0h

- 物联网平台：1.76 × 0.95 = 1.67h

- 最终总和：2.62+1.71+2.0+1.67=8h ✓

6月2日（考勤7h）：

第一步：所有项目自由波动

- 智能传感器研发：基准 2.1h → -10%波动 → 临时 1.89h

- 工业机器人：基准 1.75h → +20%波动 → 临时 2.1h

- 新能源材料：基准 1.75h → -5%波动 → 临时 1.66h

- 物联网平台：基准 1.4h → +5%波动 → 临时 1.47h

- 临时总和：1.89+2.1+1.66+1.47=7.12h

第二步：统一调整

- 调整比例 = 7h ÷ 7.12h = 0.983

- 各项目 × 0.983 → 最终总和=7h ✓

 

核心规则总结：

- 所有项目都波动：每个项目都有随机性，看起来更自然

- 统一调整：按比例调整所有项目，确保总和=考勤

- 永不超标：调整机制保证总和始终等于考勤工时

- 月度精确：最后几天微调，确保月度总计符合目标占比

项目-设备分配矩阵

随机生成占比规则说明

一、核心规则：

  • 每个设备的研发占比总和固定为 100%
  • 同一项目-同一设备的生产占比 = 100% - 研发占比
  • 每个项目至少分配 5%，避免极端小值
  • 每次点击"随机生成占比"都会产生不同结果

二、算法步骤（开发实现参考）：

  1. 初始化基础值：给每个项目分配 5% 的基础值
  2. 计算剩余百分比：剩余 = 100 - (5 × 项目数量)
  3. 随机分配剩余部分：
    • 循环直到剩余百分比为0
    • 随机选择一个项目
    • 随机生成 1-10 的增加值
    • 给选中项目加上该值，相应减少剩余百分比
  4. 打乱顺序：对结果数组随机打乱，让分布更自然
  5. 计算生产占比：生产占比 = 100% - 研发占比

三、详细分配步骤示例（2个项目）：

初始状态：项目A=5%，项目B=5%，剩余=90%

第1次分配：随机选项目A，增加值=8 → A=13%，剩余=82%

第2次分配：随机选项目B，增加值=10 → B=15%，剩余=72%

第3次分配：随机选项目B，增加值=5 → B=20%，剩余=67%

...（继续直到剩余=0）

最终结果示例：项目A研发=45%，项目A生产=55%；项目B研发=55%，项目B生产=45%

四、关键点：

  • 每次只给一个项目加1-10%
  • 可以重复选择同一个项目多次
  • "增加值"是直接累加的（例：5%+8%=13%）
  • 手动修改研发占比时，生产占比会自动更新为 100% - 研发占比

提示：点击"随机生成占比"按钮即可随机生成所有设备的占比！

说明：设备工时按所选“设备考勤人员”加载其绑定项目，并按“项目绑定设备”生成分配矩阵；矩阵中只开放已绑定的项目-设备组合。设备每日工时仅分配到该人员有考勤的日期；每列设备占比建议不超过100%，设备工时上限根据企业作息、维护时间和研发占比自动计算。

随机生成占比规则说明

核心规则：

  • 每个无形资产的研发占比、生产占比总和建议分别为 100%
  • 只给已绑定的项目-无形资产组合生成占比
  • 每个项目至少分配 5%，避免极端小值
  • 应用分配后，会按所选考勤人员有考勤的日期拆分到每日

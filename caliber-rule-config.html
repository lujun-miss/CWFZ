研发费用加计扣除

适用口径：
费用类别 (八大费用)：

系统内置规则

允许微调
加计扣除

其他费用限额

与研发活动直接相关的其他费用，总额不得超过可加计扣除研发费用总额的10%

其他费用
6项费用 ÷ 9

※ 6项费用组成备注：

人员人工费 + 直接投入 + 折旧费用 + 无形资产摊销 + 设计费用 + 装备调试与试验费

倒推法逻辑解析：

1. 设 6项费用之和 = 90万，其他费用 = 20万

2. 理想研发总额 = 90万 ÷ 90% = 100万

3. 其他费用上限 = 100万 × 10% = 10万

故：20万 > 10万，此时以10万计入

高企认定

委托境内研发 (高企)

委托境内机构或个人进行研发活动所发生的费用，按照境内实际发生额的80%计入

委托外部研发
境内实际发生额 × 80%
高企认定

委托外部研发 (高企)

委托外部研发费用按80%计入，且不超过研发总费用的40%。符合高新技术企业认定管理办法相关规定。

委托外部研发
min(80%, 40%上限)

※ 自主研发费用定义：

人员人工 + 直接投入 + 折旧 + 无形资产摊销 + 设计费 + 装备调试费 + 其他费用

1. 确定计算基数 (总研发费用)

公式：自主研发 + 境内委托×80% + 境外委托×80%

示例：20 + 40×80% + 60×80% = 100万

2. 境内占比校验 (≥60%)

境内费 = 自主研发 + 境内委托×80% = 52万

校验：52 / 100 = 52% 低于60%

结论：由于境内占比不达标，境外研发费用计入为 0

3. 境外限额校验 (≤40%)

若境内达标，境外计入额 = min(境外实际×80%, 总研发费×40%)

本例限额：100 × 40% = 40万

高企认定

其他费用限额 (高企)

与研发活动直接相关的其他费用，一般不得超过研发总费用的20%

其他费用
6项费用 ÷ 4

※ 6项费用组成备注：

人员人工费 + 直接投入 + 折旧费用 + 无形资产摊销 + 设计费用 + 装备调试与试验费

倒推法逻辑解析：

1. 设 6项费用之和 = 80万，其他费用 = 30万

2. 理想研发总额 = 80万 ÷ 80% = 100万

3. 其他费用上限 = 100万 × 20% = 20万

故：30万 > 20万，此时以20万计入

高企认定

科技人员在司工时限制

科技人员实际年度工作时间需累计满183天以上（按实际考勤工作日）

人员人工
在司工时 ≥ 183天

高企硬性指标解析：

※ 政策要求：

1. 科技人员是指直接从事研发及相关技术创新活动，以及专门负责研发活动管理的人员。

2. 累计实际工作时间必须 ≥ 183天。

3. 计算口径：按实际考勤工作日来算，剔除节假日及非研发相关请假。

※ 归集影响：

若某科技人员当年在司时间不足183天，则该人员全年的工资、奖金、五险一金等人工费用均不得计入高企口径研发费用。

加计扣除

委托境内研发 (加计)

委托境内机构或个人研发费用，按境内实际发生额的80%计入加计扣除基数

委托外部研发
境内实际发生额 × 80%
加计扣除

委托境外机构研发 (加计)

委托境外(不包括境外个人)进行研发活动所发生的费用，按照费用实际发生额的 80%计入委托方的委托境外研发费用。
委托境外研发费用不超过境内符合条件的研发费用三分之二的部分，可按规定在企业所得税前加计扣除。

委托外部研发
min(80%, 三分之二上限)

计算步骤演示：

※ 自主研发费用定义：

人员人工 + 直接投入 + 折旧 + 无形资产摊销 + 设计费 + 装备调试费 + 其他费用

设：自主研发=40万，委托境内=40万，委托境外=60万

1. 境内符合条件研发费 = 40 + 40×80% = 72万

2. 境内费用的2/3上限 = 72 × 2/3 = 48万

3. 境外费用的80%部分 = 60 × 80% = 48万

结论：取两者最小值，即最终境外计入 48万

特殊收入冲减研发费

下脚料、试制产品销售等特殊收入应全额冲减对应项目的研发费用

特殊收入
100% 冲减 (A107012)

企业在研发过程中形成的试制产品、下脚料等，销售时应按其实际销售收入冲减对应的研发费用。

结转逻辑解析：

1. 设：某项目当期总费用 100万，特殊收入 120万

2. 当期冲减：100万 (费用减至0)

3. 结转处理：余额 20万 待结转

备注：余额将结转至以后年度，继续冲减该项目的研发费用。
